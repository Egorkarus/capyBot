# capyBot 🍊

Самодовольная капибара — музыкальный бот для вашего Discord-сервера. Она ленива, харизматична и любит слушать музыку, пока греется на солнышке.

Бот умеет воспроизводить музыку из YouTube, SoundCloud, Twitch, по прямым ссылкам на MP3/MP4 файлы, а также проигрывать аудио/видео файлы, прикрепленные напрямую к сообщениям в Discord.

---

## 🚀 Команды

Префикс бота: `!` (можно изменить в `src/config.js`)

### Для всех пользователей
* **`!play <ссылка/файл>`** — Воспроизвести музыку или видео. Поддерживаются ссылки на YouTube, SoundCloud, Twitch, прямые ссылки на `.mp3`/`.mp4` или прикрепленный к сообщению MP3/MP4-файл.
* **`!skip`** — Пропустить текущую песню и перейти к следующей в очереди.
* **`!pause`** — Поставить воспроизведение на паузу.
* **`!resume`** — Снять воспроизведение с паузы.
* **`!queue`** — Показать список следующих треков в очереди.
* **`!help`** — Показать справочное сообщение с командами бота.

### Только для Администраторов (👑)
* **`!join`** — Пригласить капибару в ваш текущий голосовой канал.
* **`!leave`** — Выгнать капибару из голосового канала.
* **`!stop`** — Остановить воспроизведение музыки и полностью очистить очередь.
* **`!reload`** — Горячая перезагрузка (HMR) логики команд и событий на лету без отключения от голосового канала.

## 📁 Структура проекта

Проект организован по стандартам чистого кода:
```text
├── .github/
│   └── workflows/
│       └── deploy.yml        # GitHub Actions CI/CD пайплайн
├── src/                      # Вся логика и код бота
│   ├── commands/             # Команды бота (help, play, skip, reload...)
│   ├── events/               # Динамические обработчики событий (messageCreate, ready, voiceStateUpdate)
│   ├── structures/           # ООП структуры (GuildSession)
│   ├── utils/                # Утилиты (logger, reloader)
│   ├── CapyClient.js         # Класс клиента (ООП-обертка над discord.js Client)
│   ├── config.js             # Выделенная конфигурация сообщений и таймаутов
│   └── index.js              # Точка входа
├── Dockerfile                # Оптимизированный Dockerfile
├── docker-compose.yml        # Docker Compose с поддержкой HMR через volume
├── package.json              # Зависимости и скрипты
├── .env.example
└── README.md
```

## 📦 Запуск бота

### Вариант 1. Запуск через Docker (Рекомендуемый)

Убедитесь, что у вас установлены **Docker** и **Docker Compose**.

Запуск контейнера в фоновом режиме:
```bash
docker-compose up -d --build
```

Остановка контейнера:
```bash
docker-compose down
```

### Вариант 2. Локальный запуск (Node.js)

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Полезные скрипты запуска:
   * `npm start` — стандартный запуск бота.
   * `npm run dev` — запуск в режиме разработки.
   * `npm run clean` — очистка локальной папки `temp`.
